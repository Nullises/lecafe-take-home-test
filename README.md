## Dev Mode

1. *Setting Environment:* Install Expo in your Mac/PC, following instructions below:
https://docs.expo.dev/get-started/set-up-your-environment/

3. Run `npm install` (YOU MUST HAVE INSTALLED NODE 18.2 AT LEAST)

4. Run `npm run start` or `npx expo start` (YOU MUST HAVE INSTALLED EXPO ALREADY)

5. Press `i` for iOS Simulator or `a`for Android Emulator and will install Expo Go


## Run in physical device with Expo Go (Recommended)

If you want see the app in a physical device:

1. Install Expo Go through App Store (iOS) or Google Play Store (Android)
2. Follow every step from Dev mode, except the last one
3. Scan QR Code to see the App in physical device
